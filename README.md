
# Contagem Regressiva ENEM

Um projeto simples de contagem regressiva para o ENEM, desenvolvido com HTML, CSS e JavaScript.

O objetivo do projeto é criar uma página que mostre quanto tempo falta para a prova e, ao mesmo tempo, servir como prática dos principais conceitos de desenvolvimento web.

---

##  Objetivo

Criar uma página de estudos para acompanhar a contagem regressiva para o ENEM, contendo:

- Contagem regressiva em tempo real;
- Lista de matérias para revisar;
- Checklist de matérias;
- Interface simples e agradável.

---

 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página;
- **CSS3** — estilização e layout;
- **JavaScript** — lógica da contagem regressiva e interação com a página.
